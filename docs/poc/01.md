# POC #1 — Registration + Lifecycle Dispatch

**Status:** PASS (with one correction to architecture doc)
**Date:** 2026-05-21
**Graphics.GD version:** `v0.0.0-20260521203745-bcb92de10087`
**Godot version:** `4.6.2.stable.official.71f334935`
**Platform:** Windows 11, amd64

## Hypothesis

A Go struct embedding `Node.Extension[T]` and registered via `classdb.Register[T]()`, instantiated as a scene root, has its `Ready()` method called once when entering the tree and `Process(delta)` called every frame — dispatched by method name with no manual trampoline.

## Result

✅ **Confirmed.** Output from a 6-frame run:

```
[POC1] main() entered, registering Probe
[POC1] calling startup.Scene()
[POC1] Probe.Ready called
[POC1] Probe.Process tick=0 dt=0.008333
[POC1] Probe.Process tick=1 dt=0.008333
[POC1] Probe.Process tick=2 dt=0.013475
[POC1] Probe.Process tick=3 dt=0.015254
[POC1] Probe.Process tick=4 dt=0.015507
[POC1] Probe.Process tick=5 dt=0.015641
[POC1] PASS — Ready fired once, Process fired 6 times. Exiting.
[POC1] Probe.Process tick=6 dt=0.030910
```

## Findings

### 1. Lifecycle dispatch is by method name, no trampoline

Both `Ready()` and `Process(...)` are picked up off the registered struct purely by name. No `_Ready` shim, no method table, no manual hookup. Confirms ARCHITECTURE.md §6 "verified fact" #2.

### 2. ⚠️ `Process` takes `float32`, not `float64`

ARCHITECTURE.md and the upstream `gddocs/` examples both show `Process(delta float64)`. The current Graphics.GD `gdclass` machinery rejects that signature with a hard panic:

```
panic: gdextension.RegisterClass: Method Probe.Process does not match ._process
    is func(*main.Probe, float64) want func(gdclass.Receiver, float32)
```

**Action:** Phase 1 wrapper types must declare `Process(delta float32)`. Recommend exposing this through `gogogd.Delta` as a type alias so future changes (e.g. if upstream switches to `Float.X`) are absorbed in one place. Update `docs/ARCHITECTURE.md` §6 fact #2 and §10 examples.

This is **load-bearing** for §6 wrapper-type signatures (`NodeExt[T]`, `Node2DExt[T]`, etc.).

### 3. Registered type can be a scene root

`main.tscn` containing `[node name="Probe" type="Probe"]` works — Godot recognizes the user-registered class as a node type and uses it as the scene root. This is what makes `Ready()` fire.

If the scene root is a vanilla `Node` (default `gd` template), no `Ready`/`Process` fires on any registered type — they would need to be instantiated as children explicitly. Phase 1's `gogogd new` template must write `main.tscn` with the user's `Game` component as root, not a bare `Node`.

### 4. `SceneTree.Get(node).Quit()` is the right exit path, but it's async

After calling `Quit()`, `Process` fires once more before the engine actually unwinds. Not a problem, but worth knowing for any helper that promises immediate exit semantics. The `Process(7)` line in the output proves it.

### 5. Toolchain reality on Windows

- `gd` CLI (`C:\Users\hello\go\bin\gd.exe`) bootstraps `project.godot`, `main.tscn`, `library.gdextension`, etc. when run in an empty directory.
- `gd` manages Godot itself (`~\gd\bin\godot.exe`) and zig (`~\gd\bin\zig.exe`) under `$GDPATH`.
- `gd run --headless` does **not** work — `--headless` is forwarded to `go build` and rejected. To run headless: build manually with `CC=zig cc go build -buildmode=c-shared -o graphics/windows_amd64.dll`, then `godot --headless` from `graphics/`. The `gogogd dev` CLI must split build flags from Godot flags.

## What this means for the plan

| Plan item | Action |
|---|---|
| §6 wrapper types | Switch `Process` signature from `float64` to `float32`. Same for `PhysicsProcess` and any other delta-receiving virtuals — POC #1 verified Process only |
| `gogogd new` template | Must scaffold `main.tscn` with the user's component as root, not a bare `Node` |
| `gogogd dev` / `gogogd run` | Must NOT forward Godot flags to `go build`. Need explicit flag separation (e.g. `gogogd run -- --headless --foo`) |
| Architecture revision | Update §6 fact #2 and §10 code samples to `float32`. Worth a v0.9 revision once a few more POCs land |
